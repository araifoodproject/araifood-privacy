১. আমরা কী ধরনের তথ্য সংগ্রহ করতে পারি

AraiFood ব্যবহারের সময় প্রয়োজন অনুযায়ী নিচের তথ্য সংগ্রহ করা হতে পারে:

  • Account Information: নাম, মোবাইল নম্বর, Email address, Password-এর নিরাপদ/প্রযুক্তিগত তথ্য, Profile photo, Account-related information।
  • Delivery Information: Delivery address, Location-related information প্রয়োজন অনুযায়ী, Contact number, Delivery instructions।
  • Order Information: Order ID, Food/Pharmacy products-এর তথ্য, Quantity, Order amount, Order status, Restaurant/Pharmacy information, Delivery information।
  • Payment Information: Payment processing-এর জন্য প্রয়োজনীয় transaction-related information সংগ্রহ বা সংরক্ষণ করা হতে পারে। তবে Customer-এর সম্পূর্ণ card number, card PIN, CVV, mobile banking PIN বা password AraiFood সরাসরি সংরক্ষণ করবে না, যদি না কোনো অনুমোদিত payment service-এর প্রয়োজনীয় secure process-এর অংশ হিসেবে তা প্রযোজ্য হয়।
  • Gaming Top-Up Information: Game Name, Game ID / UID, Player ID, Server information, Top-Up amount, Transaction information। Gaming Top-Up-এর জন্য Customer-এর game password, OTP বা personal login credentials প্রয়োজন নেই এবং এগুলো AraiFood-কে প্রদান করা উচিত নয়।
